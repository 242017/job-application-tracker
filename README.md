# Job Application Tracker

Aplicacion web creada con React y Vite para organizar postulaciones laborales durante una busqueda de empleo.

## Descripcion

Job Application Tracker es una herramienta personal para registrar empresas, cargos, ubicaciones, enlaces, estados y notas de cada postulacion. El proyecto esta pensado como una pieza de portafolio para un Junior Full Stack Developer, con una interfaz moderna, responsive y enfocada en una necesidad real.

## Problema que resuelve

Cuando se aplican a muchas vacantes al mismo tiempo, es facil perder informacion importante: donde se aplico, en que estado esta el proceso, cual era el enlace de la vacante o que notas se deben recordar. Esta aplicacion centraliza esa informacion y la guarda en el navegador con LocalStorage.

## Funcionalidades

- Agregar nuevas postulaciones laborales.
- Guardar empresa, cargo, ubicacion, enlace, estado y notas.
- Estados disponibles: Applied, Interview, Offer y Rejected.
- Eliminar postulaciones.
- Filtrar postulaciones por estado.
- Ver estadisticas generales del pipeline.
- Guardar la informacion en LocalStorage.
- Diseno responsive para escritorio, tablet y movil.

## Tecnologias

- React
- JavaScript
- CSS
- LocalStorage

## Como instalar

```bash
npm install
```

## Como ejecutar

```bash
npm run dev
```

Despues abre la URL local que Vite muestre en la terminal.

## Como crear una version de produccion

```bash
npm run build
```
